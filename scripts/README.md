# Scripts

This folder contains lightweight reproduction and analysis helpers.

- `aggregate_results.py`: scans stored oracle result files and produces `results/benchmark_summary.csv`.
- `reproduce_figures.py`: collects final paper-ready figures into the top-level `figures/` folder.
- `run_example_pipeline.sh`: documents the main experiment entry points.

The full experimental sweep is computationally expensive; stored outputs are included so the main claims can be inspected without rerunning everything.
