# Experiment Design

Experiments cover five datasets: CIFAR-10, CIFAR-100, SVHN, FashionMNIST, and EMNIST-Balanced.

Each dataset is partitioned across 20 clients using Dirichlet label-distribution splits with alpha values 0.1, 0.3, and 1.0.

Each setting is evaluated across multiple random seeds and three personalization policies.
